Privacy Policy

Last updated: July 29, 2026

1. Overview

Kukku is designed to run AI features primarily on-device. We aim to minimize data collection and keep user content private.

2. Data We Process

Kukku may process text prompts, uploaded documents, selected images, profile details (such as display name/avatar), and optional tool configuration to provide app features.

3. On-Device Processing

By default, core AI inference is performed locally on your device.

4. When Data May Leave Device

If you enable tools or modes that use external services, relevant query data is sent to those providers to return results. Examples include web search providers, weather providers (Apple WeatherKit with Open-Meteo fallback), and third-party API tools you configure.

Web search: Web search is optional and is not configured by default. It only sends data once you add your own search provider API key, and results are clearly attributed to their source.

Remote and external models: Kukku runs local AI on-device by default. If you enable Escalation mode or connect an agent to a remote model or an OpenAI-compatible external endpoint using your own API key, the relevant prompt and context for that request are sent to the provider you configured. Kukku asks before routing a task to a more powerful model.

5. Permissions

Depending on features you use, Kukku may request access to camera, microphone/speech recognition, photos, contacts, calendars/reminders, health data (HealthKit), location (for weather and geocoding), and local network discovery.

6. Backups

Backup files may include app settings and agent/tool setup. API keys are redacted from backups and must be re-entered after restore.

7. Data Sharing

We do not sell personal data. Data is only shared with external providers required for enabled features, such as Apple WeatherKit/Open-Meteo for weather and providers you configure for optional tools.

8. Subscription and Monetization Events

Kukku generates subscription and paywall event logs to support onboarding diagnostics and entitlement reliability. These events are designed to avoid personal content such as prompt text, email body text, phone numbers, contacts, or message text.

Event fields may include install/session identifiers stored on your device, app version/build metadata, paywall and subscription outcomes, product identifiers, optional country/currency metadata, and sanitized error codes/messages. In this app version, these events are processed locally on-device and are not used for cross-app tracking.

9. Data Retention and Deletion

Most app data is stored locally on your device. You can delete content in-app or uninstall the app to remove local app data, subject to your device backup settings.

10. Children

Kukku is not directed to children under 13.

11. Contact

For privacy requests or questions, contact support@ibhanai.com.
