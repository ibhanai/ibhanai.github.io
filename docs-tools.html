Personal AI Kukku Me Tools Guide

A practical reference for end-user tools currently exposed in Kukku. Use the index below to jump to each tool section. Kukku native skills (Habit Tracker, Expense Tracker) are documented separately in the Skills Guide; note that skills and tools cannot be assigned to the same agent.

Scope and Access

  • This page includes only currently visible end-user tool types.
  • Hidden/internal tools are intentionally excluded from public docs.
  • Kukku also has skills (native Habit Tracker and Expense Tracker, plus additional skills per the skills.md standard). Skills and tools cannot be assigned to the same agent — see the Skills Guide.
  • Agents can also escalate to a remote or OpenAI-compatible model using your own API key; Kukku asks before sending data off-device.
  • Premium Subscription: Required for Analyzer mode and all tool orchestration. Direct mode does not run tool flows.

Tool Metadata That Changes Routing

  • Tool name: Keep it specific to the capability; vague names weaken selection quality.
  • Tool description: Explain exactly when the tool should be used and what it returns.
  • Keyword routing: Add high-signal keywords that match real user intent phrases.
  • Usage examples: Provide realistic examples so the model learns correct invocation patterns.

After editing a tool: Re-open each affected agent, remove and re-add that tool, then save the agent so updated configuration is applied.

Web Search

Use this tool to retrieve current web information when your question depends on fresh or external data.

  • Best for: news checks, quick verification, and source-backed summaries.
  • Example prompt: "Find the latest update on topic X and summarize key points."

Weather

Provides local weather conditions and forecast context.

  • Best for: trip planning, outdoor scheduling, and forecast lookup.
  • Example prompt: "What is the weather tomorrow in Singapore?"

Date and Time

Resolves current date and timezone-related time questions.

  • Best for: timezone conversion, schedule confirmation, current time lookup.
  • Example prompt: "What time is it now in New York?"

Calculator

Performs arithmetic and quick numeric calculations.

  • Best for: totals, percentages, and unit-style numeric checks.
  • Example prompt: "Calculate 18% tip on 86.50 and total amount."

Calendar

Reads and manages events when calendar permissions are granted.

  • Best for: meeting lookup, conflict checks, and event planning.
  • Example prompt: "Do I have free time between 3 PM and 5 PM tomorrow?"

Reminders

Creates and updates reminders and personal task items.

  • Best for: simple task capture with due dates and follow-ups.
  • Example prompt: "Remind me to send the report at 9 AM tomorrow."

Contacts

Finds recipient details for communication workflows.

  • Best for: resolving names to phone/email targets before sending.
  • Example prompt: "Find Priya's mobile number in my contacts."

Email

Composes or sends email through configured account integrations.

  • Best for: draft generation and assisted email workflows.
  • Example prompt: "Draft an email to product team with this status update."

Gmail

Handles Gmail-specific mail actions when Gmail integration is enabled.

  • Best for: Gmail draft/send/search workflows.
  • Example prompt: "Search my Gmail for invoices from last month."

iMessage

Supports iMessage sending flows with recipient resolution.

  • Best for: quick text communication from inside Kukku.
  • Example prompt: "Send Alex: I will join in 10 minutes."

WhatsApp

Prepares and routes WhatsApp message actions.

  • Best for: fast chat communication with known recipients.
  • Example prompt: "Message Nikhil on WhatsApp: meeting moved to 4 PM."

Telegram

Supports Telegram messaging workflows with configured access.

  • Best for: direct or channel-oriented communication tasks.
  • Example prompt: "Send a Telegram update: deployment completed successfully."

Image Analysis

Extracts and explains visual information from images shared in chat.

  • Best for: OCR-style reading, scene interpretation, and visual QA.
  • Example prompt: "Read the text in this image and summarize it."

Knowledge Base

Uses uploaded files to answer document-grounded questions.

  • Best for: contracts, policies, reports, and reference documents.
  • Example prompt: "Find termination terms in this file."

Important: If automatic tool routing is not triggered, use the Files option and reference terms like "this file", "uploaded document", or "recent pdf" in your prompt to activate document-aware fallback behavior.

Limitations: Max import pages and file size are adjusted automatically based on available device memory. Higher-memory devices can import larger and longer PDFs.

Custom Tool

Runs user-defined tool configurations for domain-specific tasks.

  • Best for: private APIs and custom actions not covered by default tools.
  • Example prompt: "Run my CRM sync tool and summarize new leads."

MCP Client Tool (Experimental)

Lets an agent call tools exposed by a configured Model Context Protocol (MCP) server.

  • Best for: extending Kukku with additional actions beyond the built-in tools.
  • Enable first: Model Setup → Tooling Features → Enable MCP Client Tool. The MCP Client type then appears here in Tools.
  • Configure: Server URL, Authentication (Bearer token / Header API key / Query API key / None), API Key / Token, and optional secret; plus advanced filters (include / exclude tools, read-only only, max tools, discovery mode).
  • Example prompt: "Use my connected MCP tool to fetch today's open tickets."

Full walkthrough: field-by-field setup and connection examples are in the User Guide. Experimental: MCP support is early and may change across releases.
